Demo script: one trip through all four steps

  1. Assistant: type a trip, for example 3 travellers to Rome, departure 10 September 2027, return 17 September 2027, budget 3,000 EUR. The skill checks it. When it is complete, enter the customer email and click Send to Intake. (Tip: first try Test 4 to show that missing data is found.)
  2. Intake: press Go, open the new request (status New), click Read with AI (fields are filled, Ready for Review), then Approve: sales order created in mock S/4HANA, and the trip is sent on as TO-<sales order>.
  3. Overview: press Go: the same trip TO-… is there. Select it and click Generate AI Insights.
  4. After-Booking: press Go and open TO-…: same customer, dates and price. Cancel it (refund by the 90 / 50 / 0 % rules) and approve the refund as manager.

The trip moves from app to app through SAP CAP actions on SAP BTP, protected by a shared key. The price in Overview and After-Booking is the customer's budget. S/4HANA is simulated with a mock service in the SAP API format. The Assistant is a local copy of the Joule agent, because students cannot deploy it. All data is invented sample data.
