Demo script

  1. Assistant: click Test 4 and send. The request has no return date; the skill finds it. Then click Test 1: 1,500 EUR, 40 days before departure gives 1,350 EUR with manager approval.
  2. Intake: open request BRQ10008 (Japan, German message) and run the AI analysis. Then open BRQ10003 (Mallorca, Ready for Review) and press Approve: the sales order is created in mock S/4HANA.
  3. Overview: open booking BO-2001 (Oslo, unpaid, departs soon) and generate the AI insights: summary, priority and alert.
  4. After-Booking: open AB-1001 (Mallorca, 1,500 EUR) and cancel it: 90 % = 1,350 EUR, same as the Assistant said. Approve the refund as manager.

Each app has its own database, so a booking does not move from one app to the next by itself. S/4HANA is simulated with a mock service in the SAP API format. The Assistant is a local copy of the Joule agent, because students cannot deploy it. All data is invented sample data.
